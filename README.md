# Glyph

Glyph is a lightweight flat-file CMS written in pure PHP.

Designed for bloggers, hobbyists, and small websites, Glyph provides a fast and simple publishing experience without requiring a database.

## Features

- Flat-file content storage
- PHP 8.3+
- No database required
- Theme support
- Plugin system (planned)
- Media uploads
- Built-in installer
- Extensible architecture

## Status

Early development.

## Requirements

- PHP 8.3+
- Apache or Nginx
- JSON, mbstring, fileinfo, and openssl PHP extensions
